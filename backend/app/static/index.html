Detection Modality Profiles

Underlying mathematics, signals, and implementation details for the 4 detection techniques

Internal-State Analysis Method A

1. EigenScore

Decomposes the token hidden-state representation matrix H ∈ R^(T × D) from intermediate and late decoder layers. Computes the Gram/covariance matrix spectrum eigenvalues λ_1 ≥ λ_2 ≥ ... ≥ λ_T and spectral von Neumann entropy.

S_spectral = - ∑ p_i log(p_i)
Effective Rank = exp(S_spectral)
Low Dispersion: Structured representation manifold (factual).
High Dispersion: Spectral collapse / uncertainty (hallucination).
Stochastic Sampling Method B

2. Self-Consistency

Samples N stochastic responses at temperature T = 0.7–0.9. Employs cross-sentence NLI logic to compute the fraction of sampled responses that fail to support or contradict the claim.

Score = (1 / N) ∑ [1 - Entailment(sample_i, claim)]
Consensus ≥ 80%: Consistent assertion.
Divergence: Conflicting claims across model generations.
Semantic Uncertainty Method C

3. Semantic Entropy

Overcomes token-entropy flaws by clustering sampled responses into semantic equivalence classes C_1, ..., C_K using bidirectional entailment.

H_semantic = - ∑ P(C_k) log2 P(C_k)
Normalized = H_semantic / log2(N)
K = 1 (Entropy 0.0): All answers share identical meaning.
K > 1 (High Entropy): Model proposes mutually exclusive facts.
Factual Grounding Method D

4. Retrieval Verification

Retrieves top-k evidence passages from verified knowledge corpora (PubMed, FDA, Python docs) using BM25 and dense vector search, classifying claims into Supported, Contradicted, or Unverifiable.

3-Way: Supported (0), Contradicted (1), Unverifiable (1)
Provides complete explainability and citation traces for clinical audits.
